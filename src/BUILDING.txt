BUILDING SpellLeveling.dll

This is the complete source of the plugin (licensed GPL-3.0-or-later, see LICENSE.txt one folder above this one in the release archive). The scripts are for Windows
and PowerShell. The default paths in the scripts are the author's; every one can be passed as a parameter or
set in an environment variable, as below.

WHAT YOU NEED
  - Visual Studio 2022 with "Desktop development with C++" (MSVC v143, a Windows SDK). It was built with Community.
  - CMake 3.21 or newer (the one that comes with Visual Studio works).
  - Git.
  - vcpkg, and CommonLibSSE-NG (below).

1. COMMONLIBSSE-NG (the exact version this was built with: 13.1.0, commit 12d61f3c39f7d4ba1b1ab543df2bca0e613dc747)
     git clone https://github.com/alandtse/CommonLibSSE-NG extern/CommonLibSSE-NG
     cd extern/CommonLibSSE-NG
     git checkout 12d61f3c39f7d4ba1b1ab543df2bca0e613dc747
     git submodule update --init --depth 1
   (Or keep it elsewhere and set the COMMONLIB_DIR environment variable, or pass -CommonLib to build.ps1.)

2. VCPKG
     git clone https://github.com/microsoft/vcpkg extern/vcpkg
     extern\vcpkg\bootstrap-vcpkg.bat
   Keep the full history (no --depth): vcpkg.json pins the package versions with a "builtin-baseline" commit.
   (Or set SPL_VCPKG_ROOT, or pass -Vcpkg to build.ps1.) The dependencies (spdlog, fmt, DirectXTK, DirectXMath,
   rapidcsv) are fetched and built by vcpkg on the first build, with the triplet x64-windows-static-md.

3. BUILD
     powershell -ExecutionPolicy Bypass -File build.ps1
   The first build takes several minutes (it compiles CommonLibSSE-NG); later ones a few seconds.
   The result is package\SKSE\Plugins\SpellLeveling.dll and SpellLeveling.ini, ready to copy into Data.
   The build folder is %LOCALAPPDATA%\spl-build (kept short on purpose: MSBuild's file tracker fails on long paths).
